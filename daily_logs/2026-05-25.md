## 产品与技术动态

### 本周重点：GLM-5.1高速版API上线
- **性能突破**：400 tokens/s，官方声称为全球最快大模型API推理速度
- **市场意义**：速度×成本双优势加强企业客户黏性，对实时场景（对话机器人、代码补全、工作流自动化）尤为关键
- **定价策略**：高速版采用溢价定价，进一步验证"量价齐升"商业逻辑

### GLM-5.1 核心里程碑回顾（本月持续发酵）
- 5月12日：在Artificial Analysis Coding Agent Index中排名全球开源第一
- SWE-bench Pro：全球第三 / 国产第一 / 开源第一（超过Claude Opus 4.6）
- 8小时持续自主工作能力，开源唯一验证案例
- AIME 2026：95.30分；HLE：52.30分

### AutoGLM智能体进展
- 手机端AI Agent（Open-AutoGLM）开源，支持Android/鸿蒙/iOS
- 多模态视觉理解屏幕，自动操作微信、淘宝、抖音等应用
- GLM-5.1在前端/后端/长程任务平均提升20%，实际编码体验接近Claude Opus 4.5水平

### 本周竞争格局变化重点

**正面变量**：
- 百川和零一万物退出通用赛道，行业格局向头部集中，智谱直接受益
- 大厂（阿里、腾讯）选择"投资智谱"而非全面自研竞争，降维打击烈度低于预期

**负面变量**：
- DeepSeek V4.1定档6月开源——若性能持续超预期，将压低整个行业的API定价天花板
- 阶跃星辰提速IPO——港股AI供给增加，分流资金和估值锚点下移压力

**大厂降维分析**：字节（豆包）、阿里（通义）、百度（文心）均有自研大模型，但均已战略跟投智谱/阶跃，表明"共生"比"竞争"更符合当前利益。DeepSeek开源才是真正的定价破坏者，而非大厂。

## 今日投资信号

### 积极信号
1. **港股通纳入预期**：一旦正式纳入，将有数百亿港元南向资金强制买入，是最强潜在催化剂
2. **恒生科技指数纳入**：国际指数基金配置需求，ETF跟踪买盘
3. **商业化加速验证**：API ARR突破USD 2.5亿（同比60倍），定价权清晰
4. **发改委政策加持**：政府明确表态支持AI落地，降低监管不确定性

### 风险提示
1. **七月解禁（最高优先级风险）**：锁定期届满，20%+总股本上市流通，大概率带来抛压，可能引发-20%~-40%回调
2. **DeepSeek V4.1（6月）**：若开源再度超预期，将压制商业API定价逻辑，引发智谱估值重构
3. **阶跃星辰IPO分流**：港股AI供给增加，现有AI股筹码承压
4. **现金流时钟**：账面约70亿，年烧约50亿，2026年底至2027年初触及再融资窗口
5. **高估值脆弱性**：任何一条增长预期下修，都可能引发剧烈反应（20-40%下跌空间）

### **今日建议**：等待回调，重点关注周一走势
- **建议依据**：
  - 上周五已大涨26.93%，本周一开盘大概率面临获利了结压力或区间震荡
  - **当前位置（约HK$1,278）不适合追高**——P/S 735倍无法靠基本面自圆其说
  - **关键支撑位**：HK$1,050（5月13日高点附近）/ HK$950（5月初水平）
  - **理想布局区间**：若回调至HK$950-1,100，可考虑5%以内仓位小额试探
  - **止损参考**：若跌破HK$800（约较5月22日收盘跌37%），需重新评估技术面趋势
  - **七月前操作原则**：减少持仓、锁定部分利润，六月底前须对7月解禁做出仓位预案
- **中期观点**（3-6个月）：若恒生科技指数纳入落地+港股通纳入同步兑现，+50%至HK$1,900以上有想象空间；若DeepSeek V4.1冲击叠加7月解禁，则可能回调至HK$700-800区间。
